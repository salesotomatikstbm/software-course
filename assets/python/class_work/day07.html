Understanding the For Loop in Python

Syntax of a For Loop

The basic syntax of a `for` loop in Python looks like this:

# Basic For Loop syntax
for item in sequence:
    # code to execute for each item
    print(item)  # Output: item from the sequence

1. For Loop with List

Loop through each item in a list:

# Loop through a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)  # Output: apple, banana, cherry

2. For Loop with range()

Use range to generate a sequence of numbers:

# Loop through a range
for i in range(5):
    print(i)  # Output: 0, 1, 2, 3, 4

3. Nested For Loop

Use a for loop inside another for loop:

# Nested for loop
for i in range(3):
    for j in range(2):
        print(f"i: {i}, j: {j}")  # Output: i: 0, j: 0, i: 0, j: 1, i: 1, j: 0, i: 1, j: 1, i: 2, j: 0, i: 2, j: 1

4. For Loop with Sum Calculation

Sum the values in a list using a for loop:

# Sum the numbers in a list
numbers = [1, 2, 3, 4, 5]
total = 0
for num in numbers:
    total += num
print(total)  # Output: 15

5. For Loop with Even Numbers

Loop through numbers and print only the even ones:

# Loop through numbers and check if even
for num in range(10):
    if num % 2 == 0:
        print(num)  # Output: 0, 2, 4, 6, 8

6. For Loop with Odd Numbers

Loop through numbers and print only the odd ones:

# Loop through numbers and check if odd
for num in range(10):
    if num % 2 != 0:
        print(num)  # Output: 1, 3, 5, 7, 9

7. For Loop with Numbers Greater than 5

Loop through numbers and print those greater than 5:

# Loop through numbers and check if greater than 5
for num in range(10):
    if num > 5:
        print(num)  # Output: 6, 7, 8, 9

8. For Loop with Numbers Divisible by 3

Loop through numbers and print those divisible by 3:

# Loop through numbers and check if divisible by 3
for num in range(10):
    if num % 3 == 0:
        print(num)  # Output: 0, 3, 6, 9
