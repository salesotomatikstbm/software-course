Project Selection

Choose any one project from the list below. There are 4 projects we practiced in class and 4 new projects to challenge yourself.

Project Requirements

  • Your project must use at least some of these: Formatted String, User Input, Functions, Loops, Conditional Statements, and Calculations.
  • If you get stuck, you may refer to the sample code provided for each project.

Presentation (PPT)

Once your project is working, create a PowerPoint using the template: Otomatiks-Presentation-Template.pptx

Link to download the presentation template

Your presentation must include the following slides:

  1. Title Slide Project name
  2. Your Details Name, grade, section
  3. Objective What does the project do?
  4. Why You Chose This Project Your reason for picking it
  5. Concepts Used Tools and features you applied
  6. What You Learned in 12 Weeks Key takeaways from the course
  7. Live Demo Show the working project
