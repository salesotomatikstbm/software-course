Course Overview

This course introduces young learners to the fundamentals of programming through Scratch, a visual programming language developed by MIT. Students will learn computational thinking, problem-solving skills, and creative expression through interactive projects.

Key Learning Outcomes:

  • Understand basic programming concepts
  • Develop logical thinking and problem-solving skills
  • Create interactive stories, games, and animations
  • Learn to collaborate and share projects
  • Build confidence in using technology creatively

Who Can Join?

This course is specially designed for young learners between 8+ years of age who want to explore the world of programming in a fun, visual way.

Perfect For:

  • Students with no prior coding experience
  • Young creators interested in making games and animations
  • Students who enjoy solving puzzles and logical challenges

Prerequisites

No prior experience needed! This course is designed for absolute beginners. The only requirements are:

  • Basic computer literacy (using a mouse and keyboard)
  • Access to a computer with an internet connection
  • Enthusiasm to learn and create

Course Curriculum

Introduction to Scratch

Learn the basics of Scratch, including motion and looks blocks, and create interactive projects.

Events and Sequencing

Learn to use events and sequencing to control the flow of your project.

Animations and Storytelling

Create fun animations and tell stories through your Scratch projects.

Variables and Conditions

Learn to work with variables, conditions, and create interactive and logical projects.

Decision Making and Game Design

Understand decision-making structures and use them to design simple games.

Variables, Lists & Data

Work with lists, data, and logic to create more complex projects.

Advanced Concepts

Explore advanced concepts, such as custom blocks and project extensions.

Final Project

Work on an exciting final project to apply all the skills learned in the course.
