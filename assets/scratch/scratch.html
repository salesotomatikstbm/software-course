Course Objective

This course introduces young learners to the fundamentals of programming through Scratch, a visual programming language developed by MIT. Students will learn computational thinking, problem-solving skills, and creative expression through interactive projects.


Key Learning Outcomes:

  • 1. Understand basic programming concepts
  • 2. Develop logical thinking and problem-solving skills
  • 3. Create interactive stories, games, and animations
  • 4. Learn to collaborate and share projects
  • 5. Build confidence in using technology creatively

Who Can Join?

This course is specially designed for young learners between 8+ years of age.


Prerequisites

No prior experience needed! This course is designed for absolute beginners.


What's Next After the Course?

  • Continue exploring advanced Scratch projects
  • Transition to text-based programming (Python, JavaScript)
